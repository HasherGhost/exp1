# Merio assets

This folder contains the game's original pixel-art asset generator.

- Run `python -m assets.generate_assets` to create the PNG sprites.
- `main.py` automatically generates any missing sprites on first launch.
- The assets are original simple pixel art made with Pygame drawing primitives; they are not ripped from Mario or Nintendo games.

For additional ready-made, freely usable platformer art, Kenney's **Pixel Platformer** pack is CC0: https://kenney.nl/assets/pixel-platformer
